# Student Marks Analysis

## Project Overview
A Python project to analyze student marks across five subjects.

## Subjects
- Python
- Operating System
- R Programming
- Java
- Gender and Diversity

## Features
- Student-wise and subject-wise averages
- Highest and lowest marks
- Pass percentage
- Grade distribution
- Students needing academic support
- Personalized remarks
- Marks validation
- Basic charts

## Technologies
Python, NumPy, Pandas, Matplotlib, Jupyter Notebook

## How to Run
Open the notebook in Jupyter Notebook or Google Colab and run the cells in order.
